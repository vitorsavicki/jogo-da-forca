# Contribuindo 🤝

Contribuições são bem-vindas! O projeto é propositalmente simples:
**HTML + CSS + JavaScript puros, zero dependências, zero build.**

## Regras da casa

1. **Sem dependências de npm/CDN** — é uma decisão de segurança e simplicidade (ver `_headers` / CSP).
2. **Nada de código inline** — scripts e estilos ficam em arquivos próprios (a CSP proíbe inline).
3. Palavras novas entram em `js/words.js` (sem acentos, maiúsculas, com categoria e dica).
4. Abra uma **issue** antes de mudanças grandes — vamos conversar!
5. Use os templates de issue/PR — eles existem para ajudar. 💜

## Rodando local

Abra `index.html` no navegador ou sirva com `npx serve .`.
